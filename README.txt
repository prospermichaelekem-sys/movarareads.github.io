HOW TO PUBLISH FREE WITH GITHUB PAGES
1. Create a free GitHub account at https://github.com
2. Create a new public repository named exactly: yourusername.github.io (replace yourusername with your GitHub username).
3. Upload index.html, style.css, script.js and the assets folder into the repository root.
4. In repository Settings > Pages, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for deployment. Your site will be at https://yourusername.github.io
